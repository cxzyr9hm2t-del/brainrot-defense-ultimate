# 🧠 Brainrot Defense Ultimate

An ADHD-friendly browser game that combines tower-defense gameplay with encouragement messages and break reminders. Built as a single HTML file and deployed via GitHub Pages.

## ✨ Features

- **Tower-Defense Gameplay** — Defend against waves of "brainrot" enemies
- **ADHD-Friendly Design** — Easy mode, clear visual cues, and manageable pacing
- **Encouragement System** — Positive messages to keep you motivated
- **Break Reminders** — Built-in prompts to take healthy breaks between sessions
- **Responsive Layout** — Plays on desktop, tablet, and mobile browsers
- **Zero Dependencies** — Single `index.html` file, no build step needed
